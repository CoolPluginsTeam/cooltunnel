# Introducing CoolTunnel by Cool Plugins

CoolTunnel is a free, open-source Windows utility that turns local development
sites into temporary public preview links.

It supports Local, Laragon, XAMPP, WampServer and WordPress, including Local Site
Domains, custom localhost ports, subfolder installations and reversible
WordPress URL handling.

CoolTunnel requires no account, collects no telemetry and keeps settings on the
user's computer.

Created by Satinder Singh at Cool Plugins LLP.
