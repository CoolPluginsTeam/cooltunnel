CoolTunnel Privacy Notice

This notice applies only to the CoolTunnel desktop utility and its product pages. It is separate from policies covering other Cool Plugins products and services.

Our privacy approach

CoolTunnel is designed without an account system, telemetry, advertising identifiers or behavioral analytics. Cool Plugins LLP does not receive your local site content, local filesystem paths, tunnel logs or saved profiles through the app.

Information stored on your computer

The app stores settings, profiles, migration state and preferences in your Windows application-data directory. Session logs remain in memory. WordPress backups are stored beside files that CoolTunnel edits.

Diagnostic exports

A diagnostic bundle is created only when you request it. Usernames, home folders, WordPress paths, tokens and executable paths are redacted by default. You control whether local paths are included and whether the resulting file is shared.

Cloudflare Quick Tunnels

When you start a tunnel, web traffic to the generated public URL is transmitted through Cloudflare's infrastructure and then to your local web server. Cloudflare operates independently and its handling of that traffic is governed by its own terms and policies.

GitHub downloads and updates

Installers, update metadata and source code are distributed through GitHub Releases. Visiting GitHub or downloading an update may provide GitHub with standard connection information such as an IP address and browser or client details.

Product website

The CoolTunnel product pages may generate ordinary server access logs used for security and reliable delivery. These pages do not require a CoolTunnel account and should not include product-specific behavioral tracking.

Support information

If you contact support, Cool Plugins LLP receives the information you choose to provide. Remove sensitive site content, credentials and unnecessary filesystem paths before sharing screenshots or diagnostic bundles.

Changes and contact

Material changes will be dated on this page and summarized in CoolTunnel release notes. Questions can be submitted through the CoolTunnel support page.
