Report an issue

Use GitHub Issues for reproducible bugs and feature requests. Do not include private site content or credentials.

Open GitHub Issues →

What to include

  • CoolTunnel version and Windows version.
  • Local server type: Local, Laragon, XAMPP, WampServer or other.
  • The shape of the local URL, with private names anonymized if necessary.
  • What you expected and what happened.
  • A redacted diagnostic bundle from About → Export Diagnostic Bundle.
Never publish secrets. Remove passwords, API keys, customer data, private source code and personally identifying filesystem paths before submitting an issue.
