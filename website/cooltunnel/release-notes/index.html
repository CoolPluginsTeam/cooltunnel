Current release

CoolTunnel 2.0.0

The branded production release, upgrading Local to Cloud into a maintainable public utility by Cool Plugins LLP.

Version 2.0.0

CoolTunnel identity

  • New CoolTunnel name, icon, installer, executable and product metadata.
  • About page credit for Satinder Singh at Cool Plugins LLP.
  • MIT open-source license and privacy-first product pages.

Compatibility and migration

  • Migrates profiles, settings and preferences from Local to Cloud 1.x.
  • Recognizes and safely replaces legacy managed WordPress fixes.
  • Supports Local Site Domains, Localhost router mode, virtual hosts, custom ports and subfolder sites.

Distribution

  • GitHub-hosted source, releases and update metadata.
  • Staged automatic-update rollout support.
  • Release checks for branded metadata, cloudflared, checksums and Windows signing.

Before public production rollout

Production installers are required to carry a valid Authenticode signature whose publisher is exactly Cool Plugins LLP. Verify the checksum and signature shown with the official release.
